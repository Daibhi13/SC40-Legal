Mid Distance Analysis — Support

Mid Distance Running Performance Analysis for iOS.

Getting Started

Logging a Session

Tap 'New Session' to log a running workout. Enter distance, time, and splits for each rep or interval. Save when done.

Understanding Trends

The Trends tab shows per-distance analysis including best times, average times, speed scores, and trend direction. Select a specific distance or view all distances at once.

Running Distances

Supported Distances

Mid Distance Analysis supports 800m, 1500m, mile, and 3000m distances. You can also log custom distances with manual entry.

Speed Scores

Speed scores are calculated based on your time relative to expected elite times for each distance. Scores range from 0-100.

Subscription

Mid Distance Analysis Pro

Pro unlocks advanced analytics, race predictions, split analysis, performance sharing, and more. Enjoy a 1-week free trial when you first install the app.

Data & Privacy

Local Storage

All session data is stored locally on your device. No data is sent to a server. Optional location access may be used to fetch weather conditions for your sessions.
