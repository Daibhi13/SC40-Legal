Decathlon & Heptathlon Performance Analysis for iOS.

Getting Started

Logging a Session

Tap 'New Session' to log a training or competition session. Select your event type, enter performances for each event, and save when done.

Event Types

Decathlon

Decathlon events include 100m, long jump, shot put, high jump, 400m, 110m hurdles, discus, pole vault, javelin, and 1500m.

Heptathlon

Heptathlon events include 100m hurdles, high jump, shot put, 200m, long jump, javelin, and 800m.

Scoring

Points Calculation

Scores are calculated using official IAAF scoring tables for each event. The app totals your points across all events and tracks your progress over time.

Subscription

Multi Event Coach Analysis Pro

Pro unlocks advanced analytics, event comparisons, performance sharing, and more. Enjoy a 1-week free trial when you first install the app.

Data & Privacy

Local Storage

All session data is stored locally on your device. No data is sent to a server.
